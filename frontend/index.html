How it works

Three steps from sign-up to secure storage.

Create your account

Register with your email and a password.

Security built in, not bolted on

Multiple independent layers protect every upload and download.

Verified identity

Every API request carries a token that the server verifies with Supabase Auth.

Private storage

Files live in a private bucket with no public links and no direct browser access.

Validated uploads

File type, size and real content signature are checked on the server.
